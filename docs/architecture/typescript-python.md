# TypeScript + Python Hybrid Service Boundary

## 1. Division of Responsibilities

| Responsibility Area | Primary Language | Reason & Optimization |
| :--- | :--- | :--- |
| **User Interface (UI/UX)** | TypeScript (React 19) | Reactive rendering, type-safe components, Tailwind CSS styling |
| **API Gateway & Routing** | TypeScript (Node.js) | Fast I/O, universal request routing, authentication middleware |
| **Multi-Tenancy & RBAC** | TypeScript | Strict memory and database query boundaries |
| **Billing & GST Metering** | TypeScript | Append-only financial ledger with 18% GST calculation |
| **Conversation State & Inbox**| TypeScript | Real-time WebSocket/SSE state and agent-human handoff |
| **Vector Embeddings** | Python (FastAPI) | High-performance batch vector generation |
| **Semantic Reranking** | Python (FastAPI) | Cross-encoder relevance scoring and candidate reordering |
| **RAG Hallucination Scoring** | Python (FastAPI) | Grounding verification and token faithfulness metrics |
| **Document Intelligence** | Python (FastAPI) | Document parsing, text cleaning, and structural chunking |
| **NLP Classification** | Python (FastAPI) | Intent detection, entity extraction, and sentiment analysis |

---

## 2. Inter-Service Communication Protocol

- **Protocol**: HTTP/1.1 REST JSON + SSE Streaming
- **Authentication**: Shared HMAC token via X-Internal-Token header.
- **Tenant Context**: Propagated via X-Tenant-ID header.
- **Distributed Tracing**: Unique X-Request-ID generated by TypeScript and logged by Python telemetry middleware.
- **Circuit Breaker**: TypeScript maintains a 3-state circuit breaker (CLOSED, OPEN, HALF_OPEN) with a 10s cooldown.
